# VortexUI

Suite de componentes **Angular 22+** (Signals, Standalone, zoneless) — DataGrid, File Manager, Charts, Scheduler, AI opt-in e temas Fluent / LDS.

- **GitHub:** https://github.com/JoelSchecheleski/vortex-ui  
- **npm (público):** [`@joel_jsp/vortex-ui`](https://www.npmjs.com/package/@joel_jsp/vortex-ui)  
- **PRD:** [VortexUI-PRD.md](./VortexUI-PRD.md)

## Quick start (consumidor)

```bash
npm install @joel_jsp/vortex-ui
```

```ts
import { VxDataGridComponent } from '@joel_jsp/vortex-ui';
```

```css
@import '@joel_jsp/vortex-ui/styles/vortex-ui.css';
```

## Monorepo (dev)

```bash
npm install
npm start                 # Gallery http://localhost:4200
npm run build             # build da lib
npm run prepare:npm       # artefato em dist/libs/vortex-ui
npm run publish:npm       # publica no npm (conta logada)
```
