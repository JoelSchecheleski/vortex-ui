# vortex-ui/ai

Secondary entry point for VortexUI AI Foundation.

## Usage

```ts
import {
  VortexAIIntegration,
  VortexMockAIIntegration,
  VxAiAssistantDialogComponent,
  VxAiPromptEditorComponent,
} from 'vortex-ui/ai';
// monorepo alias:
// import { ... } from '@vortex-ui/ai';
```

Keep this entry opt-in: apps that never enable AI should import only from `vortex-ui`.
